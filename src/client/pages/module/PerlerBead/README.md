# 拼豆图处理模块 (PerlerBead)

移植自 libudu/LinAI 的 `2f1b928ada87f6c4d25ccef9d61d90df86abfe63`，在 openLinAI 中适配现有图库、路由、明暗主题、中英文与手机布局。保持浏览器本地计算，不引入服务端模块或新依赖。

入口位于工作室的“拼豆 / 像素图”工具标签，与 NovelAI、Civitai、Photopea 并列；暂存台图片可直接送入处理。旧 `/perler-bead` 链接会跳转并选中工作室里的对应工具。

拼豆工具的右侧面板默认收起，不占用画板宽度；展开或收起按钮位于原图工具栏“更换图片、从图库选”的右侧，使用左右三角形，不单独占用一行。展开后可切换“暂存台”和“生成图片”，后者跟随任务列表当前文件夹，展示该文件夹中各任务的全部输出图片；切换文件夹时回到第一页。点击图片卡的 `←` 载入原图画板，手机布局下同时收起面板。

本模块为 AI 生成图片及手绘图提供拼豆制作前处理能力：导入图片后自动识别或手动配置网格，将每个网格单元归一化为一个颜色，并支持高清预览、取色规则配置、单格精细修订、豆子用量统计以及导出纯净像素图。

成品预览的闪电按钮切换整图所有同色格子的透明状态；旁边带方框的闪电按钮按油漆桶方式，只切换选中格上下左右相连、同色且透明状态相同的区域，斜角接触不算连通。选中透明格后使用相同按钮恢复原色与色号；HEX 模式按精确颜色判断，拼豆色号模式按当前品牌的色号判断。透明格不计入用量；整图闪电操作统一同色格子的状态，更换图片或重置会清除透明设置。

导出菜单提供“导出拼豆图纸”：先转换为拼豆色号，随后导出完整 PNG 方格图纸，包含已生效的拼豆版本、行列尺寸、总豆数、颜色数、四边从 1 开始的坐标及全部色号用量图例。每格至少 36 像素，色号按底色自动选择黑白文字，每 5 格加粗网格线；透明格保留设为透明前的底色，不标色号，也不计入用量。图纸不受预览渲染模式、网格开关、缩放或选框影响；未转换时点击会提示先转换，不自动改变配色。

成品预览的网格线按钮旁提供「☉」拼豆渲染开关：默认使用原有方形像素，开启后显示带圆孔、边缘和高光的圆形拼豆，按行列比例保证豆子间距一致。拼豆模式中网格线按钮改为米色底板（钉板）开关；网格线与钉板分别记住开关状态。颜色与用量统计不受渲染模式影响，不自动隐藏白色豆子。导出像素图保留原有高清及 1:1 行为，下拉菜单新增“导出拼豆预览图”，使用当前钉板开关、完整网格和相同拼豆样式，不含选框与缩放平移；隐藏钉板时 PNG 间隙和圆孔透明。

原图工具栏与编辑模式均提供“原图对照、恢复原图、减少颜色”。按住对照（鼠标、触摸或空格/回车）显示刚载入的图片，松开返回当前图片；原始图片独立保留，不受最近 10 次编辑历史裁剪影响。恢复原图可撤销，保留网格与单格配色设置。减少颜色处理当前图片：可指定 1–256 色（含 128/64 等快捷选项），或按 RGB 距离阈值 0–442 自动合并相近色。自动优化保留高频代表色，不连锁合并；阈值 12 可将 `#F2F6F0、#EFEFED、#EDEDEB` 归并到高频或同频时最先出现的 `#F2F6F0`。处理在 Web Worker 中执行，保留原尺寸和透明度，完成后显示前后颜色数，并更新拼豆预览与用量。编辑模式中先形成可撤销的草稿，再通过“应用编辑”提交；取消丢弃草稿。

取色缩放使用最近邻，避免大图缩到 1200 像素时插值制造新颜色。减色结果同时保存拼豆调色板（透明像素按白底可见色生成），格子取色、现有单格覆盖、用量清单及导出统一归并到该调色板，因此指定 16 色时拼豆结果不超过 16 色。调色板随草稿及原图历史撤销、重做；旋转、翻转和裁剪保留调色板，恢复原图、更换图片或新增画笔编辑解除限定。

首期为纯前端本地处理，不修改原图文件，不新增后端持久化数据，切换其他导航页面时通过 Zustand 内存状态自动保活。

默认保留 HEX 调色板，可用于像素图。在用量清单上方选择 MARD 221 / 291 及匹配算法后，点击“转换”才应用：OKLab（默认）与 CIEDE2000 按感知色差匹配，RGB 距离用于对照。成品预览、单格当前色、用量统计与 PNG/TXT 导出共同使用转换结果；用量按真实色号合并。匹配在本地 Worker 中执行，处理期间暂停导出，失败回退转换前状态。转换保留底层 HEX 与原图，每次切换算法或版本都从同一 HEX 基准计算，避免反复转换累积偏色；“撤销”逐次恢复转换前的调色板，最终回到 HEX。更换输入图时清空转换状态；原图编辑、减色及网格调整继续沿用当前转换设置。参考色卡及复用算法的来源、版权与许可证保留在 `palettes/`、`colorMatching/`。

OpenWrt 仅通过现有静态路由提供前端与 Worker 资源；色卡随前端内置，匹配与导出均在访问者浏览器执行，不访问外部色卡服务、不新增 Node 依赖、不使用 Sharp，也不改变 `IMAGE_BACKEND=ffmpeg` 路径。`src/client/public/third-party/perler-matching.txt` 随前端静态资源分发完整版权与许可证。

色板菜单还支持 COCO 291、漫漫 278、盼盼 285、咪小窝 286；数字表示当前收录的已确认色号数。盼盼与咪小窝各排除 4 个未确认的占位色号。COCO 与漫漫存在相同 HEX 的不同色号，匹配时统一使用来源顺序中的首个代表色号。切换品牌仍从原始 HEX 基准计算，撤销能跨品牌逐次恢复，用量清单和图片导出随当前已应用品牌同步。

原图网格对照在画布内复用参考图编辑器，支持画笔、裁剪、旋转、翻转、缩放和平移。点击单一颜色按钮打开调色板，下方提供当前拼豆结果中用量最高的 8 个颜色。每笔涂抹结束及裁剪、旋转、翻转、撤销、重做后，右侧拼豆预览和用量统计自动更新；网格辅助线独立叠加，不写入编辑图片。取消恢复编辑前的图片，应用编辑更新当前处理图片，不上传或覆盖素材文件。已应用的原图编辑可撤销、重做，保留最近 10 个图片版本；更换输入图时重置历史，撤销后再次应用会清除后续重做分支。网格与单格配色设置保持不变。

## 核心数据模型 (`types.ts`)

- `GridSize`: `{ columns: number; rows: number }` 网格行列规格（范围 1..200，最大 40,000 单元）。
- `ColorRule`: `{ type: 'center' | 'dominant'; offsetX: number; offsetY: number; maxColors?: number }`
  - 取色规则，“主色占比”与“中心像素采样”均支持 `offsetX` / `offsetY`（范围 0.00 ~ 1.00，精度 0.01，默认 0.50 居中）四向微调；
  - 切换规则时保留已调好的偏移量，左侧原图网格辅助线与选区高亮实时跟随动态偏移，方便像素与网格精准对齐。
- `CellResult`: `{ row, column, color, sourceColors }` 单元格最终标准 6 位十六进制色（`#RRGGBB`）。
- `CellOverride`: `{ color?: string; rule?: ColorRule }` 单格独立覆盖规则。

## 关键设计与性能优化要点

### 1. 页面切换保活机制 (`store.ts`)

- 所有状态（`imageUrl`、`imageElement`、`imageData`、`gridSize`、`globalRule`、`cellOverrides` 等）托管于 `usePerlerBeadStore`；
- 从当前页面切出到左侧其他导航时，组件卸载但不销毁 store 数据，重新切回时立即恢复原先工作区；
- 仅在用户**重新选择新图片**或执行**重置**时调用 `URL.revokeObjectURL` 释放内存，避免内存泄漏。

### 2. 二维方框偏移调节与极速交互性能 (`OffsetPad.tsx` & `processing.ts`)

- **全新二维方框控制器**：替换原本的滑块，提供直观的二维操作方框（内置十字参考准星），支持点击与平滑拖拽，右侧提供 X/Y 两个精度为 0.01 的 `0.00 ~ 1.00` 输入框，并支持一键重置居中；
- **动态网格对齐**：左侧原图模式下的辅助网格线和单元格高亮框随 XY 偏移量实时联动位移，点击画布单元格时自动进行偏移逆变换，杜绝点击错位；
- **中心采样 (`sampleCenterColor`)**：直接进行单一像素内存寻址，时间复杂度严格为 $O(1)$，调整 X/Y 偏移方框时达到 60FPS+ 极速实时反馈；
- **快速主色 (`sampleDominantColor`)**：采用轻量数字聚类与无堆内存分配算法，单格计算耗时降低 95% 以上，且同样支持 XY 偏移；
- **单格原色分布 (`analyzeSelectedCellDetails`)**：同步基于单元格实际偏移区域按需计算来源色分布。

### 3. 完美像素图导出 (`ToolPanel.tsx`)

- 导出图片时**不绘制任何辅助网格线**，输出纯净的点阵像素画；
- 支持两种导出规格：
  1. **高清像素图**：自动等比整数放大（如 1200px 级别），像素方块无抗锯齿模糊，适合手机查看与图纸打印；
  2. **1:1 原尺寸像素图**：精确按 `columns × rows` 分辨率输出（1 像素 = 1 单元），适合导入 Aseprite、Photoshop 等专业像素编辑工具。

### 4. 网格规格与长宽比锁定 (`getDefaultGridSize`)

- **默认长边 50 等比配置**：图片导入时默认自动以长边为 50，按原图长宽比等比计算短边规格（如 16:9 图默认为 50×28，4:3 图默认为 50×38，9:16 图默认为 28×50）；
- **默认锁定长宽比**：控制面板中长宽比锁定开关默认为开启状态（`lockAspect = true`），调整任意一侧行列数或点击快捷尺寸预设时，自动保持原图比例等比换算。

### 5. 自动网格识别 (`processing.ts -> detectGridSize`)

- 预先降采样分析图像，避免大图高计算开销；
- 计算水平与垂直方向的边界差分突变特征，搜索 `10..150` 候选行列数，优先倾斜 50×50 附近尺寸；
- 综合边界对比度与长宽比一致性输出置信度，置信度不足时回退为默认长边 50 比例并提示用户。
